# エビデンス台帳と出典リンク

## 基本原則

一次情報、公式文書、原論文、データセット、ソースコード、元記事などを参照した場合、読者が必ず辿れるリンクを成果物に残す。記憶だけでURL、引用、数値、公開日を作らない。

本文の主張と出典は、次の鎖で管理する。

```text
主張 → エビデンスID → 出典メタデータ → 正規URL → 参照箇所
```

## エビデンスID

本文中の出典は `[E-001]` のような安定したIDにする。IDは同じ成果物内で一意にし、本文の直後または脚注から台帳へリンクする。

台帳の最低項目：

| 項目 | 内容 |
| --- | --- |
| ID | `E-001` など一意の識別子 |
| 種別 | `primary`、`official`、`paper`、`dataset`、`secondary` など |
| 著者・組織 | 出典を所有する主体 |
| タイトル | ページ・論文・データセットの正式名称 |
| 公開・更新日 | 分かる範囲で記録 |
| 版・コミット | 仕様書、コード、データの再現に必要な識別子 |
| 参照箇所 | 章、節、ページ、表、行、クエリなど |
| 正規URL | 読者が辿れるHTTPS URL、DOI、permalinkなど |
| 最終確認日 | URLと内容を確認した日 |
| 使用箇所 | 本文の章、節、図表、主張ID |
| 備考 | paywall、未確認、部分アクセスなど |

## 主張の分類

- 出典で確認できる事実：`[E-###]` を必須にする
- 複数の事実から導いた推論：`[推論]` とし、根拠のエビデンスIDを併記する
- 筆者の評価や提案：`[考察]` とし、事実と混ぜない
- まだ検証できない見通し：`[仮説]` または `[未検証]` とする

出典がない内容を、出典があるように見せるためのリンクを作らない。正規URLがない、またはアクセスできない場合は制限を明記し、確認済みの事実として断定しない。

## 出力上の要件

### HTML

- `[E-###]` から出典一覧の該当項目へ移動できる
- 出典一覧から正規URLへ移動できる
- 外部リンクの目的がリンク文だけで分かる
- URLに認証情報、ローカルパス、親ディレクトリ参照を含めない
- ページ内アンカーが重複しない

### PDF

- 本文の引用・脚注・エビデンスIDがクリックできる
- 参考文献のURLがPDFリンク注釈として残る
- 文字列としてURLを抽出できる
- 目視でリンクの欠落、脚注の切れ、参考文献の改ページ崩れを確認する

## 引用と要約

原文を長く転載せず、必要な短い引用と要約を使い分ける。引用が結論を支える場合は、出典の参照箇所を記録する。ページの読者が原文を比較できるよう、原文の正規URLを残す。
